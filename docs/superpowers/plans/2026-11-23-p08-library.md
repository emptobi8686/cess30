# P8 Library Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a private, audience-controlled academic document library: staff upload, version, publish and archive resources; students search, filter, preview PDFs, download, bookmark and report.

**Architecture:** Metadata in `library_*` tables with audience rows (P6 shape) and RLS via `can_view_library_resource`. Files sit in a private bucket with **no authenticated storage policies**. Uploads use server-issued signed upload URLs followed by a server-side finalise step (size, MIME and magic-byte checks). Reads go through a route that authorises with the user's RLS context and then redirects to a 120-second signed URL.

**Tech Stack:** Supabase Storage (signed upload and download URLs), PostgreSQL FTS + `pg_trgm`, Next.js 16 route handlers and server actions, Zod 4.

**Spec:** `department-expansion/04_LIBRARY_MODULE_ASSESSMENT.md`; `06` §1–2 and §6 (R1–R5, R11, R13).

## Global Constraints

- **Gate 🔐:** the copyright and past-question policy in decision 0004 must be approved.
- Bucket `library`: `public = false`, `file_size_limit = 26214400` (25 MB). Allowed MIME: `application/pdf`, `application/vnd.openxmlformats-officedocument.presentationml.presentation`, `application/vnd.ms-powerpoint`, `application/vnd.openxmlformats-officedocument.wordprocessingml.document`, `application/msword`, `image/png`, `image/jpeg`, `text/plain`. No SVG, HTML, macro-enabled Office formats or archives.
- Object path is always `resources/{resource_id}/{file_id}.{ext}`, generated by the server. The extension comes from the detected MIME type.
- No `storage.objects` policy for `authenticated` or `anon` on bucket `library`. Only the service role touches objects.
- Signed URL TTL: 120 s for download and 300 s for preview. Never log or store them.
- Preview only for PDF. Office formats are download-only (no external converter in this phase).
- No new runtime dependency (magic-byte detection is hand-written).

## Review Focus

- A file renamed `notes.pdf` that is actually an HTML or ZIP file must be rejected at finalise, and its object deleted.
- A student hitting `/api/library/<id>/file` for a resource of another level must receive 404 (not 403, to avoid leaking existence).
- Replacing a file while a student holds an old signed URL must not break the new version; the old version remains downloadable only by staff.
- A search for `"; drop table` or `%_` must return safe results and no error.
- A removed (takedown) resource must disappear from search, bookmarks and related lists immediately.

### Task 2: File validation

**Files:**
- Create: `src/features/library/file-validation.ts`
- Test: `src/features/library/__tests__/file-validation.test.ts` (fixtures in `src/features/library/__tests__/fixtures/`: tiny `sample.pdf`, `sample.pptx`, `sample.docx`, `sample.png`, `fake.pdf` (HTML content), `macro.pptm`)

**Interfaces:**
- `type LibraryMime = "application/pdf" | "application/vnd.openxmlformats-officedocument.presentationml.presentation" | "application/vnd.ms-powerpoint" | "application/vnd.openxmlformats-officedocument.wordprocessingml.document" | "application/msword" | "image/png" | "image/jpeg" | "text/plain"`
- `detectMime(head: Uint8Array, zipEntryNames?: string[]): LibraryMime | null`. Signatures: `%PDF-` → pdf; `89 50 4E 47` → png; `FF D8 FF` → jpeg; `D0 CF 11 E0` → OLE, mapped using the declared type to ppt or doc; `PK 03 04` → OOXML only if `[Content_Types].xml` is among the zip entries and `ppt/` or `word/` exists, and with **no** `vbaProject.bin`; printable UTF-8 with no NUL bytes in the first 4 KB → `text/plain`.
- `validateLibraryUpload(input: { declaredMime: string; sizeBytes: number; head: Uint8Array; zipEntryNames?: string[] }): { ok: true; mime: LibraryMime; ext: string } | { ok: false; reason: "too_large" | "type_not_allowed" | "content_mismatch" | "macro_content" }`
- `safeDisplayFilename(name: string): string` (strip path separators and control characters, collapse whitespace, max 120 characters, keep the extension)

- Create: `src/features/library/upload-actions.ts` (`"use server"`):
  - `startLibraryUploadAction(input: { resourceId: string; declaredMime: string; sizeBytes: number; originalFilename: string }): Promise<ActionResult<{ fileId: string; path: string; token: string }>>`: checks `requireCapability("library_manager", scopeOf(resource))` and the size and type allow-list.
